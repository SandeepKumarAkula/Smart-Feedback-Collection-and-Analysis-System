How It Works

Smart Feedback Collection

A full-stack Flask web application that enables users to submit feedback with automatic sentiment analysis, role-based access control, and comprehensive admin analytics dashboard.

Role-Based System

Supports three roles: Guest (anonymous feedback), Registered Users (personalized feedback history), and Admin (analytics and management dashboard).

Sentiment Analysis

Automatically analyzes feedback tone (Positive, Negative, Neutral) using TextBlob, providing deep insights into user satisfaction trends.

Admin Analytics Dashboard

Displays six interactive charts: Sentiment Pie, Donut, Category Bar, Rating Bar, Timeline, and Stacked Sentiment Chart — all powered by Chart.js 4.4.0.

⭐ Intelligent Rating System

Interactive 5-star rating with smooth hover, click feedback, and automatic average score tracking.

🔐 Security & Performance

Secure password hashing, email-based password reset, CSRF protection, and smooth 60fps UI rendering ensure a reliable and fast user experience.
